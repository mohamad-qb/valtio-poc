Deal editor

The same app, built with several state-management libraries.

  • Valtio — src-valtio/
    Proxies with key subscriptions.
  • MobX — src-mobx/
    Observables with computed values and actions.
  • MobX-State-Tree — src-mobx-state-tree/
    Typed models with views and actions; each product's data one immutable value.
  • mobx-keystone — src-mobx-keystone/
    Class models with decorators; each product's data a plain object, observable to the leaf.
  • Legend-State — src-legend-state/
    One observable tree of plain data, set leaf by leaf; listeners get the paths that changed.
  • Redux — src-redux/
    Redux Toolkit: one store of immutable data, events as actions, everything else derived.
  • Zustand — src-zustand/
    One store per deal of plain immutable data, actions inside it; one set per batch, validation as selectors.
  • Jotai — src-jotai/
    Atoms in atoms: a data atom per product, everything else derived; every action a write atom, so one batch.
  • Effector Nested — src-effector-nested/
    The same, with nested state: groups hold their products by id.
  • Effector Model — src-effector-model/
    @effector/model: a store per group and product, read and written by dot path.
